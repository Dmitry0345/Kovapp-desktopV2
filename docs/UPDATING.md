# Переход на новую версию системы тестирования

1. Если прогон идёт или сервер поднят — остановите: `run.cmd stop`.
2. Сохраните свой `.env`, например в `F:\env-backup.env`. В нём ваши
   настройки: `PARALLEL`, внешний сервер, учётные записи.
3. Переименуйте старую папку, например в `F:\kovapp_autotest-old`. Журналы
   прошлых прогонов останутся в её папке `logs`.
4. Распакуйте новый архив в `F:\` — появится новая `F:\kovapp_autotest`.
5. Скопируйте свой `.env` в новую папку поверх того, что пришёл в архиве.
   Если в новой версии появились параметры, их список и значения по
   умолчанию — в `.env.example` и `docs\SETTINGS.md`.
6. Распакуйте новую версию проекта в `F:\kovapp_autotest\project` — в
   папке должен остаться только новый проект, без файлов старого.
7. Запустите `run.cmd`. Образы Docker пересобираются из кэша за пару минут:
   проект и код тестов подключаются к контейнерам при каждом запуске и в
   образ не входят.
8. Проверив новую версию, старую папку можно удалить.
