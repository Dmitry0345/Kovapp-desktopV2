Все варианты проверки — команда: {RUN} <вариант> [разделы]
Без разделов проверяются все разделы; разделы пишутся через пробел (список — в конце).

ПОЛНЫЕ ПРОГОНЫ — база, сервер и тестовые данные поднимаются в Docker сами
  {RUN} all                       всё подряд: веб-версия, Android (APK на ПК и эмулятор), сжатие, нагрузка, ПК-версия
  {RUN} web [разделы]             веб-версия: разделы сайта во всех браузерах, темах и размерах экрана
  {RUN} android [разделы]         Android целиком: интерфейс APK на ПК, затем приложение на эмуляторе
  {RUN} android-pc [разделы]      только интерфейс APK на ПК
  {RUN} android-device [разделы]  только приложение на эмуляторе Android Studio
  {RUN} device-both               два прогона на эмуляторах: с сервисами Google и без (DEVICE_AVD_NOGMS)
  {RUN} device-pair               два телефона одновременно: чат и задачи в реальном времени (только Windows)
  {RUN} compression               качество сжатия: браузеры, сервер и телефон дают одинаковый результат
  {RUN} load                      нагрузка по ступеням: от LOAD_USERS человек до LOAD_USERS_MIN

ПК-ВЕРСИЯ — без Docker: Python 3.10–3.12 этого компьютера, тестовый сервер внутри прогона
  {RUN} pc [части]                всё о программе для Windows: без окон (сжатие, отправка), разделы под
                                      каждой ролью, действия, мессенджер в обеих темах;
                                      части: unit sections actions messenger
  Окна программы открываются и закрываются сами — не трогайте мышь и клавиатуру. Подробно: docs/PC.md

ПРОТИВ ВНЕШНЕГО СЕРВЕРА — ваш тестовый сервер вместо сервера в Docker
  {RUN} external [разделы]          веб-версия против сервера EXTERNAL_BASE_URL
  {RUN} android-external [разделы]  интерфейс APK на ПК против того же сервера
  Перед запуском заполните в .env:
    EXTERNAL_BASE_URL=http://адрес:порт   сервер на этом же ПК: http://host.docker.internal:порт
    EXTERNAL_ADMIN_LOGIN, EXTERNAL_ADMIN_PASSWORD   администратор этого сервера
    EXTERNAL_CONFIRM_TEST_SERVER=1        подтверждение, что сервер тестовый: тесты создают и удаляют данные
    EXTERNAL_CREATE_ACCOUNTS=1            учётные записи ролей тесты заведут сами, EXTERNAL_CLEANUP=1 — удалят после
  Рабочий сервер не указывайте.

РУЧНАЯ ПРОВЕРКА С ГОТОВЫМИ ДАННЫМИ
  {RUN} demo web
      Проще всего: сервер с готовыми данными — 3 проекта, 6 задач на разных этапах, чаты, склад, оборудование.
      Откройте http://localhost:{PORT}/app/ — учётные записи всех ролей на экране и в logs/demo-accounts.txt.
      Закончили — нажмите Enter в окне команды, всё остановится.
  {RUN} server
      Только сервер с пустой базой: http://localhost:{PORT}/app/  Остановить: {RUN} stop
  {RUN} stand
      Стенд: LOAD_USERS человек работают в фоне, вы проверяете сайт сами; панель стенда http://localhost:18090/
  {RUN} demo | demo phone | demo nogms   (только Windows)
      То же, что demo web, и приложение: на эмуляторе, на вашем смартфоне по USB, на эмуляторе без сервисов Google
  {RUN} demo pc [роль]
      То же, что demo web, и окно ПК-версии на этом же сервере: адрес, логины и пароли те же, сайт работает
      одновременно с программой. С ролью (director, head_mont, worker_mont, …) — вход сразу.

ТОЛЬКО ЧАСТЬ ТЕСТОВ
  {RUN} web tasks messenger         разделы через пробел — для любого варианта
  {ONLY}

  {RUN} stop        остановить всё после прерванного прогона
  {RUN} keys-check  проверить ключи Firebase из папки keys
  {RUN} video-log [phone] | login-check | notify [роль]   отладка телефона во время demo (только Windows)
