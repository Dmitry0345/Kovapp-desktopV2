# kovapp_autotest — автотесты Kovapp beta 3 (веб-версия, Android и ПК)

Один модуль вместо двух прежних (`kovcheg-autotest` и `kovapp_mobile`): сервер, сайт в Chrome,
Firefox и WebKit (движок Safari), интерфейс APK на ПК, приложение на эмуляторе Android и на
смартфоне по USB, программа для Windows (ПК-версия), качество сжатия файлов, нагрузка по
ступеням, резервные копии.

**Полная документация всех режимов — `docs/RUNNING.md`.**

## Быстрый старт на Windows

1. Docker Desktop (`docs/WINDOWS.md`); для Android — Android Studio (`docs/DEVICE.md`); для
   ПК-версии — Python 3.10–3.12 (64 бита) с python.org (`docs/PC.md`).
2. Распакуйте модуль в `F:\kovapp_autotest`. Архивы проекта `web.zip`, `android.zip` и `pc.zip`
   распакуйте в `F:\kovapp_autotest\project` — получатся `project\web`, `project\android` и
   `project\pc` (в архивах уже есть эти папки).
3. Запуск:

| Команда | Что делает |
|---|---|
| `.\run.cmd all` | полный прогон: веб-версия, Android (APK на ПК и эмулятор), качество сжатия, нагрузка, ПК-версия |
| `.\run.cmd web` | только веб-версия |
| `.\run.cmd android` | только Android |
| `.\run.cmd pc` | только ПК-версия (без Docker) |
| `.\run.cmd demo web` / `.\run.cmd demo android` | запуск с тестовыми данными для ручной проверки |
| `.\run.cmd demo pc` / `.\run.cmd demo pc director` | ПК-версия для показа руками: тот же сервер, адрес и учётные записи, что у `demo web`, сайт работает одновременно (без входа или сразу ролью) |
| `.\run.cmd demo phone` | ваш смартфон по USB, журнал видео — `.\run.cmd video-log phone` |
| `.\run.cmd list` | все варианты проверки, ручной запуск сайта, внешний сервер и разделы |
| `.\run.cmd help` | все команды |

Результат — `logs\<дата_время>_<режим>\summary.txt` (открывать первым), `full.log`,
снимки экрана, `load-report.html` и `compression-report.html`; у ПК-версии — ещё `index.html`
со снимками всех экранов.

## Что нового в beta3-v13

- Часть `actions` ПК-версии считает перезапуски программы по запуску нового процесса: прежний
  путь перезапуска с передачей сеанса удалён из программы (beta3-v16-pc).

## Что нового в beta3-v12

- `run.cmd demo pc`: программа больше не подменяет профиль Windows (`USERPROFILE`) — только папку своих
  настроек. Из-за подмены окно выбора файлов писало «Расположение недоступно … Desktop» и оставляло пустое
  белое окно, хотя файлы прикреплялись.

## Что нового в beta3-v11

- `run.cmd demo pc [роль]` — на том же сервере, что `demo web`: сервер в Docker с готовыми данными,
  адрес `http://localhost:18000`, те же учётные записи и пароли (в окне и в `logs\demo-accounts.txt`).
  Программа открывается на этом сервере, а сайт `http://localhost:18000/app/` работает одновременно
  с ней. Роль — ключ из `config\roles.yaml` (director, head_mont, worker_mont, …) или логин. Клавиша
  в окне команды закрывает программу и останавливает сервер; печать программы — `logs\demo-pc.log`.
  Нужен запущенный Docker Desktop — как для `demo web`.
- ПК-версия: новая часть `actions` в `run.cmd pc` — тема и размер без перезапуска (круг новой темы
  от нажатой кнопки, выбор уходит на сервер), переходы между разделами без отдельных окон, этап
  задачи и его журнал, шаблоны задач, загрузки, медиаконтент проекта (только фото и видео),
  подсказки, флажки, кнопка снимка, счётчик просмотра. Тестовый сервер ПК-версии научился завершать
  и возобновлять этапы с записью в журнал, создавать, менять и удалять шаблоны (только руководство),
  отдавать строки склада и записывать в журнал добавленные файлы.
- Веб-версия: тест «Завершение и возобновление этапа сотрудником отдела» проверяет, что оба действия
  записаны в журнал задачи (сервер beta3-v13 записывает и возобновление).

## Что нового в beta3-v9

- Качество сжатия: ПК-версия в общем сравнении. `run.cmd compression` после браузеров и сервера
  сжимает те же исходники кодом программы (FFmpeg из её комплекта, OpenH264) прямо на компьютере,
  затем короткий второй прогон в Docker разбирает результат и строит общий `compression-report.html`
  (в журналах — прогон `compression-pc`). Не включать — `CMP_PC=0` в `.env`.
- Мессенджер: счётчик на кнопке «вниз» прибавляет по одному и после выхода со входом без
  перезагрузки страницы, и после «сеть вернулась» (раньше — по два и больше).
- Файлы задачи добавляет любой, кому открыта задача: ожидания в `config/permissions.yaml` и
  `config/ui_rights.yaml`; новый тест — рядовой участник бросает файл в зону файлов задачи
  (компьютер и телефон) и удаляет свой.
- Телефонная раскладка карточки задачи в тестах файлов этапа и PDF: вкладка «Файлы» внизу
  (раньше тест искал кнопку компьютера и падал по времени); в просмотре — видимая кнопка «Скачать».
- Порядок списка задач: просроченные задачи теста получают срок правкой — при создании сервер
  прошедший срок не принимает.
- ПК: «карточки настроек без прокрутки» — предупреждение, если экран меньше окна снимков
  (крупный масштаб Windows); `full.log` без нечитаемых строк.

## Что нового в beta3-v7

- Проверка ПК-версии: `run.cmd pc` (`./run.sh pc`), без Docker — тестовый сервер работает внутри
  прогона, программа запускается из `project\pc` тем же Python и теми же библиотеками, что и
  при сборке `Kovapp.exe` (окружение `.venv-pc` создаётся само). Три части: `unit` — сжатие
  видео на 12 образцах FFmpeg из комплекта, фото, gzip, отпечатки, уведомления, отправка файлов,
  стили мессенджера для Chromium 83; `sections` — все разделы под 7 ролями (директор — в обеих
  темах) с проверкой прав, вёрстки и снимками; `messenger` — окна и работа мессенджера в обеих
  темах. Итог — `summary.txt` и `index.html` со снимками. Подробно — `docs/PC.md`.
- `run.cmd all` — шестой частью идёт ПК-версия; `run.cmd version` показывает и её версию.
- Тесты ПК-версии — в папке `kovtest_pc` модуля.

## Что нового в beta3-v6

- `run.cmd list` (`./run.sh list`) — все варианты проверки одним списком и без Docker: полные
  прогоны, проверка против внешнего сервера (`external`, `android-external` — что заполнить в `.env`),
  ручная проверка сайта (`demo web` — проще всего, `server`, `stand`), затем разделы.
- Новый тест сервера: порядок списка задач по умолчанию — «по важности» (сначала задачи, где сейчас
  этап своего отдела: просроченные, на сегодня, остальные; затем остальные задачи в том же порядке),
  сброс фильтра возвращает этот порядок, явная сортировка по-прежнему работает.

## Что нового в beta3-v5

- Тесты на Android касаются кнопки только после того, как она перестала двигаться: шторка
  «Сортировка и фильтры» успевает выехать, касание не уходит мимо.
- После ввода текста тест ждёт клавиатуру: страница сжимается под неё, и «Отправить» в чате
  нажимается уже на новом месте.
- Описание этапа на телефоне вводится как у сотрудника: касание поля → окно письма → текст →
  «Готово»; сохранение на сервере ждётся до 10 с.
- В проекте на телефоне все разделы — широкие строки: «Склад» ищется по названию.
- Если точку касания закрывает другой элемент, в `full.log` пишется, какой именно.

## Что нового в beta3-v4

- Тесты на Android учитывают раскладку телефона: в карточке задачи — вкладки внизу («Этап», «Файлы»,
  «Файлы этапа»), в проекте — вкладки «Задачи · N» и «Файлы · N», фильтры проектов — в шторке
  «Сортировка и фильтры» с выбором организации своей шторкой. На планшете — прежняя раскладка.
- Файлы группы в чате считаются по общей группе (в истории каждый файл — своя запись).
- Закрытие просмотра свайпом вниз проверяется на неприближенном фото: приближенное свайп двигает.

## Что нового в beta3-v3

- `run.cmd keys-check` проверяет и сторону телефона: принимает ли Google ключ API приложения из
  `google-services` (с подписью отладочной сборки, как у телефона). Если нет — пишет причину и
  отпечаток SHA-1 подписи, который нужно добавить в Firebase.

## Что нового в beta3-v2 (после первого полного прогона)

- Тема и масштаб проверяются в ключе своего устройства (`web.settings.pc` / `web.settings.mobile`);
  подготовка тестов ставит тему во все ключи.
- На телефоне фильтры — шторкой снизу, на ПК — окном; тесты и обход кнопок закрывают шторки («×»)
  и раскрытые списки выбора (Escape); проверка вёрстки считает шторку верхним слоем.
- Новый просмотр фото и видео «Свет кадра»: кадр — `.mv-stage`, «Скачать» — кнопка просмотра;
  на телефоне плитка файла — карточка: касание открывает, «⋯» — скачать и удалить.
- Пересылка части группы — от самой группы, как в приложении.
- Уход в другой раздел во время обрыва: отправка продолжается в фоне и доходит целиком.
- Страница считается готовой, когда скрылась полоска «Подключение…» и применились тема и масштаб.

## Что нового в beta3-v1

- Модули объединены; прежние команды (`full`, `mobile`, `device`, `demo site`) работают.
- Отдельные папки вариантов приложения: `project\web`, `project\android`, `project\pc` (ПК — позже).
- `run.cmd load` — нагрузка по ступеням от `LOAD_USERS` до `LOAD_USERS_MIN` со сравнением
  времени ответа и графиками (`load-report.html`).
- `run.cmd compression` — качество сжатия: браузеры, сервер, телефон и ПК-версия дают одинаковый результат.
- Сервер в Docker — как рабочий: несколько процессов за nginx, MariaDB с настройками рабочего
  сервера и журналом транзакций, резервные копии.
- Проверки обеих линий: права (83 действия), мессенджер (счётчик новых, пересылка части группы),
  список задач без мигания, обрывы сети в чате, проекты (завершение, только чтение).
