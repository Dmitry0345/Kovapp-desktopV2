# Kovapp для компьютера (Windows) — beta3-v16-pc

Настольное приложение Kovapp: задачи, проекты, склад, оборудование, сотрудники, организации,
уведомления и мессенджер. Это прежнее приложение, доведённое до веб-версии beta3 v12: те же
разделы, права, окна и цвета обеих тем, тот же сервер. Окна — на PySide6 (Qt 6, лицензия
LGPL v3) вместо PyQt5 (GPL): программу можно продавать с закрытым кодом, условия — в разделе
«Лицензии — простыми словами». При сборке код компилируется в машинный (Nuitka), поэтому
исходного кода Python в готовой программе нет и восстановить его нельзя.

Мессенджер — не копия, а та же страница переписки, что у сайта (`chat.js`, `chat.css`),
открытая внутри окна приложения. Всё, что сайт делает через браузер (выбор файлов, окна,
уведомления Windows, сжатие видео), здесь делает Python — через «мост» `web_chat/pc/bridge.js`.

## Запуск без сборки

1. Установите Python 3.10, 3.11 или 3.12 (64 бита) с сайта python.org. В установщике отметьте
   «Add python.exe to PATH».
2. Дважды щёлкните `run.cmd`. Первый раз он сам создаст папку `.venv` и скачает библиотеки
   (несколько минут), потом откроет окно входа.

## Сборка Kovapp.exe

1. Python — как выше.
2. Дважды щёлкните `build.cmd` (или в командной строке из этой папки: `build.cmd`).
3. Код компилируется в машинный (Nuitka), поэтому сборка идёт несколько минут. Самый первый
   запуск дольше: `build.cmd` докачивает Nuitka, а если на компьютере нет компилятора C —
   предлагаемый Nuitka набор MinGW (на вопрос о скачивании отвечаем «да» автоматически, нужен
   интернет). Готовая программа — `dist\Kovapp\Kovapp.exe`.
4. Сотрудникам удобнее раздавать установщик (следующий раздел). Можно и без него: скопировать
   **всю папку** `dist\Kovapp` и сделать ярлык на `Kovapp.exe`. Устанавливать Python им не нужно.

Код самой программы скомпилирован в машинный и лежит внутри `Kovapp.exe` — ни `.py`, ни `.pyc`
в сборке нет, прочитать исходный код нельзя. Рядом с `Kovapp.exe` в папке `dist\Kovapp` лежат
веб-движок мессенджера, `web_chat`, значки, FFmpeg и тексты лицензий (`licenses`), а библиотеки
Qt и PySide6 — отдельными заменяемыми файлами (`Qt6*.dll`, `*.pyd`), как требует LGPL. Сборка сама
проверяет, что `ffmpeg\ffmpeg.exe` и `ffmpeg\ffprobe.exe` на месте.

Если Nuitka у вас не соберётся, есть запасной сборщик (он кладёт код как байт-код `.pyc`, это
слабее защищает): `python -m PyInstaller --noconfirm kovapp.spec` (нужен `pip install pyinstaller`).

Windows SmartScreen или антивирус иногда настороженно встречают новые незнакомые программы —
это не ошибка сборки. Подпись файла сертификатом организации эту проблему снимает.

## Установщик

Дважды щёлкните `build_installer.cmd` (или в командной строке из этой папки: `build_installer.cmd`).
Команда сама соберёт программу (как `build.cmd`) и упакует её в один файл —
`dist\KovappSetup-beta3-v16-pc.exe`. Номер версии в имени берётся из `Kovapp.exe`
(`tools\version_info.txt`).

Для сборки нужен Inno Setup 6 — бесплатная программа, её можно использовать и в коммерческой
деятельности. Если её нет на компьютере, команда при первом запуске сама скачает Inno Setup 6.7.3
с GitHub, сверит контрольную сумму и положит его в `tools\innosetup` — в систему ничего не
устанавливается. Уже установленный Inno Setup 6 находится сам.

Что делает установщик:

| Что | Как |
|---|---|
| системы | Windows 10 и 11, 64 бита; на других — понятное сообщение вместо установки |
| куда | сразу в `C:\Program Files\Kovapp`; Windows спросит разрешение администратора |
| интернет | не нужен: внутри уже всё — Python, Qt, веб-движок мессенджера, FFmpeg |
| значки | по выбору: в меню «Пуск» и на рабочем столе |
| ход установки | шкала прогресса; в конце — «Запустить Kovapp» (запускается от имени сотрудника, а не администратора) |
| вид | как экран входа Kovapp; светлый или тёмный — по теме Windows |
| обновление | новую версию ставят поверх старой: файлы программы заменяются целиком, выбор значков запоминается, значок, с которого сняли отметку, убирается |
| открытый Kovapp | установщик и удаление предлагают закрыть его сами |
| старая версия поверх новой | только после вопроса — случайно не поставится |
| Windows N | если нет «Пакета компонентов мультимедиа», предупреждает: программа работает, но видео внутри неё не откроется |
| удаление | «Параметры» → «Приложения» → Kovapp; настройки сотрудника (адрес сервера, тема, масштаб) остаются |
| журнал | каждый запуск пишет журнал в папку `%TEMP%` (файл «Setup Log …») — пригодится, если что-то пошло не так |

### Установка на многие компьютеры без вопросов

Для администратора (команда в одну строку, из папки с установщиком):

`KovappSetup-beta3-v16-pc.exe /VERYSILENT /SUPPRESSMSGBOXES /NORESTART /TASKS="startmenu,desktopicon"`

Без значка на рабочем столе — `/TASKS="startmenu"`. Открытый Kovapp при этом закрывается сам.
Удаление без вопросов: `"C:\Program Files\Kovapp\unins000.exe" /VERYSILENT /SUPPRESSMSGBOXES`.
Код завершения `0` — всё прошло.

### Подпись установщика (по желанию)

Неподписанный установщик Windows SmartScreen может встретить окном «Windows защитил ваш
компьютер» — тогда «Подробнее» → «Выполнить в любом случае». Подпись сертификатом организации
убирает это окно. Если сертификат есть, в том же окне командной строки перед сборкой задайте
команду подписи (`signtool` из Windows SDK; кавычки внутри заменяются на `$q`):

`set KOVAPP_SIGNTOOL=signtool sign /fd sha256 /tr http://timestamp.digicert.com /td sha256 /a $f`

и запустите `build_installer.cmd` — подписаны будут установщик и программа удаления.

### Оформление и постоянный код

Картинки установщика — `installer\images`: фон окна входа и знак Kovapp в светлом и тёмном
варианте, в размерах для масштаба экрана 100–250 %. Пересоздаются командой
`.venv\Scripts\python installer\make_images.py` — нужно, только если поменялись знак или цвета.

`AppGuid` в начале `installer\kovapp.iss` менять нельзя: по нему новая версия находит
установленную старую.

## Адрес сервера и настройки

Адрес сервера встроен в программу — `DEFAULT_HOST` в `admin_windows1/scaler.py` — и в окне
входа и настройках не показывается. Другой сервер для отдельного компьютера — строка `"host"` в
`%LOCALAPPDATA%\KovApp\settings.txt`. Там же у каждого пользователя хранятся тема, масштаб и режим
окна. Тема и масштаб меняются в разделе «Настройки» (тема — и кнопкой в окне входа) сразу, без
перезапуска: новая тема расходится кругом от нажатой кнопки, как на сайте.

## Сжатие видео, фото и документов

Перед отправкой файлы готовятся на компьютере по тем же правилам, что у сайта, телефона и
сервера: формат, размеры, частота кадров и звук одинаковые, откуда бы файл ни отправили.

| Что | Как |
|---|---|
| видео до 60 с | H.264 (OpenH264, профиль High): QP не ниже 26, поток не выше 0,08 бита на точку, ключевой кадр не реже раза в 10 с и на смене сцены; длинная сторона до 1920 (Full HD) |
| видео длиннее 60 с | то же, длинная сторона до 1280 (HD) |
| у любого видео | не больше 30 кадров/с; звук — первая дорожка, AAC 128 кбит/с стерео; MP4 с индексом в начале |
| видео, которое уже подходит | уходит как есть (H.264, не больше Full HD и нужного потока) |
| обрезка, поворот, отрезок по времени | применяются тем же проходом FFmpeg |
| фото | WebP качества 80, длинная сторона до 3200; до 300 КБ — без пересжатия |
| документы | gzip, если это даёт выгоду |

Сжатое здесь видео сервер не перекодирует: для сжатого на устройстве он допускает поток
до 0,096 бита на точку (`server_app/intake.py`), а потолок здесь — 0,08.

**Кодировщик.** Раньше видео сжимал x264 (лицензия GPL), теперь — OpenH264 (BSD). На
7 роликах (камера с рук и на штативе, движение, экран) качество в среднем то же, что у x264
(−0,3 по шкале VMAF), а видеодорожка в среднем на треть крупнее, со звуком — примерно
на четверть. Причина — в самом OpenH264: в нём нет B-кадров, а адаптивное квантование авторы
отключили, — именно это и даёт x264 его плотность. Ключевой кадр раз в 10 с вместо 4 с уже
убрал из этой разницы около 3 %. Шумоподавление (встроенное и фильтрами FFmpeg), уровни
сложности OpenH264, включённое обратно адаптивное квантование и деление кадра на части при том
же качестве файлы не уменьшили — проверено на тех же роликах.

**FFmpeg в комплекте** (`ffmpeg/`): FFmpeg 8.1.3 со сжатием OpenH264 2.6.0 и AAC, без частей
под GPL. Читает почти всё, что снимают телефоны и камеры: H.264, HEVC (H.265), AV1 (через
dav1d), VP8/VP9, MPEG-4, MPEG-1/2, ProRes, WMV, MJPEG и др.; звук AAC, MP3, Opus, Vorbis,
AC-3, FLAC, AMR и др. Сжимает всегда в H.264 + AAC — это видео открывается везде. Точный
состав и версии — `ffmpeg/versions.txt`.

Если FFmpeg недоступен или видео не удалось прочитать, файл уходит как есть и его сожмёт
сервер — отправка не ломается.

### Лицензии — простыми словами

Это пересказ условий, а не юридическое заключение: перед продажей их стоит показать юристу.

- **Код Kovapp** — ваш: его можно закрыть и продавать.
- **Qt и PySide6** — LGPL v3. Платная программа с закрытым кодом допускается, если:
  1. библиотеки Qt и PySide6 лежат отдельными файлами, которые пользователь может заменить
     своей сборкой, — сборка Nuitka так и делает (`Qt6*.dll` и `*.pyd` рядом с `Kovapp.exe` в
     папке `dist\Kovapp`); собирать всё в один файл (режим «onefile») не нужно, а если менять сам
     код Qt или PySide6 — эти изменения придётся опубликовать. Код самой Kovapp компилируется в
     машинный и к Qt/PySide6 статически не привязывается, поэтому его можно не раскрывать;
  2. вместе с программой лежат тексты LGPL v3 и GPL v3 и перечень библиотек — папка `licenses`;
  3. исходники Qt и PySide6 той же версии доступны — ссылки в `licenses/README.txt`; копии
     архивов стоит хранить у себя на случай, если ссылки перестанут работать;
  4. в лицензионном соглашении с покупателем нет запрета изменять эти библиотеки и разбирать
     программу в той мере, какая нужна для отладки таких изменений.
- **FFmpeg** — LGPL 2.1, **OpenH264 и dav1d** — BSD: тексты в `ffmpeg/`, версии и ссылки на
  исходники — в `ffmpeg/versions.txt`, сборка — `tools/ffmpeg/build_ffmpeg.sh`. FFmpeg —
  отдельная программа, которую Kovapp запускает, поэтому на код Kovapp его лицензия не влияет.
- **Остальные библиотеки** (requests, Pillow, python-dotenv и др.) — Apache, MIT, BSD, MPL:
  тексты в `licenses`.
- **Чужой код внутри исходников** — алгоритм ThumbHash (MIT), часть значков по рисункам Lucide и
  Feather (ISC и MIT), названия символов Unicode в поиске эмодзи (Unicode License V3): исходники
  открывать не нужно, достаточно уведомлений — они в `licenses` (`licenses/README.txt`).
- **Патенты на H.264** — отдельный вопрос, лицензии на код его не решают. Патентная лицензия
  Cisco распространяется только на OpenH264, скачанный самим пользователем с серверов Cisco,
  а не на собранный из исходников. У пула патентов AVC (Via LA) первые 100 000 копий в год
  бесплатны.

### Как пересобрать FFmpeg

Нужен Linux (или WSL) с `git`, `make`, `nasm`, `ninja`, `meson`, `pkg-config` и
кросс-компилятором llvm-mingw. Исходники в одной папке: FFmpeg (тег `n8.1.3`), OpenH264 (тег
`v2.6.0`, `https://github.com/cisco/openh264`), dav1d (тег `1.5.1`). Команда:

`MESON="meson" bash tools/ffmpeg/build_ffmpeg.sh win64 <папка исходников> <папка результата> <папка bin llvm-mingw>`

Готовые `ffmpeg.exe`, `ffprobe.exe`, лицензии и `versions.txt` кладутся в `ffmpeg/`. Скрипт
сам останавливается, если в сборку попала часть под GPL. Для Linux (например, для автотестов
на Debian) — та же команда с `linux` вместо `win64` и без папки llvm-mingw: получится
`ffmpeg` и `ffprobe` без зависимостей.

## Мессенджер и веб-движок

Веб-движок PySide6 6.10 — Chromium 134, и страница мессенджера идёт как есть. Замены для
старого движка (Chromium 83 у прежней сборки на PyQt5) в `kov/messenger/compat.py` оставлены:
версия движка определяется при запуске, и замены включаются, только если он старее нужного.

### Обновить мессенджер из новой версии сайта

`python tools/sync_web_chat.py <папка web_app сайта>`

Скрипт копирует файлы переписки, цвета тем и общие стили, стикеры и записывает
`web_chat/manifest.json` (что и когда скопировано). Файлы ПК в `web_chat/pc/` не трогаются.

## Проверка

Автотесты ПК-версии — в модуле `kovapp_autotest`: архив `pc.zip` распаковывают в его папку
`project`, запуск — `run.cmd pc` (подробно — `docs/PC.md` модуля). Docker не нужен: тестовый
сервер работает внутри прогона. Проверяются:

- без окон — замены стилей для старого движка, функции мессенджера, уведомления, фото,
  отпечатки файлов, gzip, сжатие видео на 12 образцах через FFmpeg из папки `ffmpeg/` (OpenH264,
  без частей под GPL, поток в пределах, которые сервер берёт без перекодирования), отправка файлов;
- все разделы под каждой ролью — пункты меню по правам, переходы, закрытые разделы, вёрстка
  (нижние панели на месте, текст в выпадающих списках не обрезан), снимки экранов;
- действия — смена темы и размера без перезапуска, переходы без пустых окон, этап задачи и его
  журнал, шаблоны задач, загрузки, медиаконтент проекта (только фото и видео), подсказки, флажки;
- мессенджер в обеих темах — окна (по центру, нужного размера) и работа: сообщения, реакции,
  правка, удаление, файлы со сжатием, пересылка, группы, входящие уведомления.

Снимки всех экранов собираются в `index.html` прогона — для просмотра глазами.

Показать программу руками — `run.cmd demo pc` модуля: поднимается тот же сервер в Docker с
готовыми данными, что у `run.cmd demo web`, и программа открывается на нём; учётные записи те же,
а сайт `http://localhost:18000/app/` работает одновременно с программой.

## Что убрано из прежнего приложения

Прежние окна и модули, которые заменены новыми и больше нигде не используются, в комплект
не входят: `chat_module/` (старый мессенджер), `api_client/` (сгенерированный клиент API),
`admin_windows1/` — всё, кроме окна входа и масштаба (`AddUser`, `Files`, `MainWindow`,
`Organizations`, `Profile`, `Settings`, `Stages`, `Tasks`, `Template` и файлы `.ui`),
`general_functions/` — `Filters.py`, `errors.py`, `user_cache.py`, `verifications.py`,
пустые папки и заглушки в корне (`Organizations`, `Profile`, `Settings`, `Tasks`, `Template`,
`chat.py`, `chat_functions.py`, `FileCategory.py`, `StageProgress.py`,
`authorization_window.py`) и файлы проекта PySide (`pyproject.toml*`). Их работу теперь
делают разделы `kov/views/` и мессенджер `kov/messenger/`.

## Если что-то не так

| Признак | Что сделать |
|---|---|
| «Не найден Python» | установить Python с python.org, отметив «Add python.exe to PATH» |
