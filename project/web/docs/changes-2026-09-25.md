# Изменения 25.09.2026 — по итогам полного прогона автотестов

| Что было | Что стало | Файл |
|---|---|---|
| Отправка файлов в группу, где человек не состоит, давала ошибку 500 (`UnboundLocalError: queue`) вместо отказа | Членство проверяется до приёма файлов, посторонний получает понятный отказ 403 и ничего не сохраняется | `server/server_app/routers/chat.py` |
| Если сотрудника добавляли в задачу позже, у него список задач обновлялся только при переключении вкладки или раз в минуту | Список задач обновляется сразу по событию «состав задачи изменился» и при правке задачи | `web_app/js/views/tasks.js` |
| После возвращения связи приложение перерисовывало открытый раздел и тем самым отменяло идущую отправку файла — докачка после короткого обрыва на телефонах не срабатывала | Пока идёт отправка, перерисовка раздела откладывается до её окончания | `web_app/js/app.js`, `web_app/js/core/files.js` |
| Файл больше 32 МБ (идёт частями) и повторно отправленный файл не сохранялись в чате: сервер отвечал 422 «Не удалось сохранить файлы» (`'LocalUpload' object has no attribute 'content_type'`) | У собранного из частей или взятого копией файла есть тип, как у обычной загрузки; чат определяет тип безопасно | `server/server_app/intake.py`, `server/server_app/routers/chat.py` |
| Отправка файла в чат при восстановлении связи отменялась: мессенджер вызывает `Kov.Files.upload()` напрямую, такую отправку `uploadsActive()` не видел, раздел перерисовывался сразу, а перерисовка обрывает идущие отправки | Любая отправка через `Kov.Files.upload()` учитывается как идущая: перерисовка ждёт её окончания, предупреждение о пропаже сети и отмена через 2 минуты действуют и для чата | `web_app/js/core/files.js` |
| Обрыв связи посреди отправки куска записывался в журнал сервера как авария с трассировкой | Одна спокойная строка: кусок не засчитан, клиент дошлёт его заново | `server/server_app/routers/uploads.py` |
| Удаление задачи оставляло в журнале предупреждение `SAWarning ... 0 were matched` | Этапы удаляются один раз, предупреждения нет | `server/server_app/routers/tasks.py` |
| «Ошибка отправки сообщения user N:» без описания, как ошибка | «Сокет пользователя N закрыт: <тип ошибки>», как обычное событие | `server/server_app/realtime.py` |

Установка как обычно: папки `server` и `web_app` поверх старых, перезапуск
сервера, на странице — Ctrl+F5. Настройки `.env` не меняются.

## Дополнение (мобильная версия)

| Что было | Что стало | Файл |
|---|---|---|
| Отложенная перерисовка не учитывала отправку файлов из мессенджера: при возвращении связи отправка в чат отменялась | Учитываются все отправки, в том числе из мессенджера; на них же распространяются правила «связь пропала — отправка продолжится» | `web_app/js/core/files.js` |
