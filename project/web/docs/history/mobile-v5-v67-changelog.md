Главное:
- **Новое:** приложение Kovapp для Android. Это тот же интерфейс, что у сайта, плюс:
  - уведомления, когда приложение закрыто, — через Google (FCM) или через собственный канал на телефонах без Google;
  - сжатие фото и видео на телефоне;
  - скачивание файлов в «Загрузки».
- **На сервере** — модуль уведомлений для приложения.
- **В веб-версии** — сенсорные экраны: размеры под палец, касание и удержание, настройки разделами, раскладка планшета.
- **Модуль автотестов** умеет проверять APK на ПК и настоящее приложение на эмуляторах Android.
