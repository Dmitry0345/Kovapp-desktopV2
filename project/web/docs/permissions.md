# Kovapp — политика прав пользователей

Состояние на 22.09.2026, после исправлений этой версии. Правила проверяет
сервер; интерфейс показывает недоступные кнопки с замком и объясняет причину.

## Роли

| Роль | Как определяется |
|---|---|
| Руководство | статус «директор» или «администратор» |
| Руководитель отдела | статус «руководитель отдела»; в отделе их может быть несколько (например, руководитель и заместитель) |
| Работник | статус «работник» |

Права зависят от поля статуса, а не от названия должности. Служебная
запись администратора скрыта из списков сотрудников, начать с ней личную
переписку нельзя.

Отделы с особыми правами:

| Отдел | Особенность |
|---|---|
| Договорной отдел | руководителей нет; любой сотрудник может быть назван ответственным за этап и получает в своём этапе права руководителя; может создавать проекты и вести справочник организаций |
| Склад | выдаёт товар со склада проекта и оборудование, принимает возврат оборудования |
| Бухгалтерия | ведёт позиции оборудования |
| Монтажный отдел, Бухгалтерия, Склад | видят склад проекта |

## Разделы меню

| Раздел | Кому доступен |
|---|---|
| Уведомления, Задачи, Организации, Оборудование, Работники, Профиль, Настройки, Мессенджер | всем |
| Проекты | всем, кроме работников монтажного отдела и отдела ТО |
| Файлы CSV | руководству |

## Задачи

| Действие | Кто может |
|---|---|
| Видеть задачу в списке и открывать её | руководство; автор, исполнители, ответственные. Участники этапов автоматически входят в исполнители |
| Создать задачу | руководство — с любыми этапами; руководитель отдела — только с одним этапом своего отдела |
| Создать задачу из шаблона | по тому же правилу |
| Править, удалить, отправить в архив и вернуть из архива | руководство; руководитель отдела, к которому относятся все этапы задачи |
| Менять этапы через правку задачи | руководство; руководитель отдела не может передать этап другому отделу, добавить или удалить этап |
| Продлить задачу на другой отдел | руководство; руководитель отдела, входящий в задачу; ответственный за последний этап |
| Журнал изменений задачи | тот, кому доступна задача |
| Запросить завершение задачи | руководство (задача сразу уходит в архив); руководитель отдела задачи; ответственный за последний этап |
| Подтвердить или отклонить завершение | руководство |

## Этапы

| Действие | Кто может |
|---|---|
| Открыть этап в окне задачи | руководство; сотрудники отдела этапа. Этап чужого отдела показан с замком |
| Править описание, завершить, возобновить этап | участник задачи из отдела этапа; руководство |
| Менять состав этапа | ответственные за этап; руководство. Если ответственных не называли — руководители отдела этапа, а в отделе без руководителей — любой его сотрудник. Себя убрать можно, только если остаётся другой ответственный |
| Кто становится ответственным при продлении | выбранные сотрудники; если никого не выбрали — все руководители отдела |
| Состав нового этапа | выбран один ответственный — только он; несколько — они и сотрудники отдела; никого — весь отдел |

## Файлы задач и этапов

| Действие | Кто может |
|---|---|
| Смотреть, открывать превью, скачивать файлы задачи | руководство; автор, исполнители, ответственные; участники и ответственные любого этапа |
| Смотреть, открывать превью, скачивать файлы этапа | у кого есть доступ к задаче (строка выше) и к этапу: руководство; сотрудники отдела этапа. Медиаконтент проекта — по тем же правилам |
| Добавить файл задачи | все, кому открыта задача: руководство; автор, исполнители, ответственные. Не в завершённом проекте |
| Добавить файл этапа | участник задачи из отдела этапа; руководство. Не в завершённом этапе |
| Удалить файл задачи | руководство; руководитель отдела задачи; тот, кто прикрепил |
| Удалить файл этапа | участник задачи из отдела этапа; тот, кто прикрепил; руководство. Не в завершённом этапе |
| Задача в архиве | файлы не добавляются и не удаляются никем |

## Проекты

| Действие | Кто может |
|---|---|
| Видеть проекты, их файлы и медиаконтент | режим `PROJECT_ACCESS_MODE=open` (сейчас) — все; режим `strict` — руководство и руководители отделов, остальные — проекты, где участвуют в задачах |
| Создать проект | руководство; руководители отделов; договорной отдел |
| Назначить ответственного | руководитель отдела становится ответственным сам; остальные выбирают руководителя отдела или директора |
| Править и удалить проект | создатель проекта и директор; администратор — нет |
| Загружать и удалять файлы разделов «Договоры», «Проект», «Сдача», «Дополнительно» | тот, кому виден проект |
| Задачи внутри проекта | в списке видны все задачи проекта; открыть задачу, её этапы и файлы — по правилам задач и этапов |
| Завершить проект, вернуть в работу | создатель, директор, администратор; завершить — только когда все задачи проекта завершены; сохраняется, кто и когда завершил |
| Вернуть в работу задачу из завершённого проекта | никто: сначала вернуть в работу проект |
| Менять что-либо в завершённом проекте: задачи, этапы, файлы задач и этапов, файлы подразделов, склад; править и удалять сам проект | никто — только просмотр; доступно лишь «Вернуть в работу» (создатель, директор, администратор). Сервер отвечает 409 |

## Файлы по прямому пути

Адреса `/file_storage/…`, `/chat/download/…`, `/file_preview/…`,
`/sheet_preview/…`. Сервер находит владельца файла и проверяет право на него.

| Владелец файла | Кто может открыть |
|---|---|
| Чат | участники любого чата, где лежит сообщение с этим файлом |
| Проект | тот, кому виден проект |
| Оборудование | все |
| Задача | по правилу «Смотреть, открывать превью, скачивать» |
| Не найден (файл-сирота) | никто |

Миниатюры и PDF-превью проверяются по исходному файлу.
`FILE_ACCESS_STRICT=0` — отказ только записывается в журнал сервера,
`FILE_ACCESS_STRICT=1` — посторонний получает 403.
