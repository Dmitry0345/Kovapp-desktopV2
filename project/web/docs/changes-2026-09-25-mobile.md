## Что добавлено для телефона

Ваше исправление откладывает перерисовку раздела, пока идёт отправка.
На телефоне к смене раздела ведут ещё два частых действия, которых на ПК
почти не бывает: **нажатие на системное уведомление** и **жест «Назад»**.
В приложении во время отправки они сначала спрашивают («Идёт отправка
файла. Перейти сейчас? Отправка файла будет отменена») — обычным окном
подтверждения веб-версии. Признак «идёт отправка» — ваш же
`Kov.Files.uploadsActive()`, поэтому поведение согласовано с сайтом.
Сайт в браузере это не затрагивает.

## Дополнительно: отправка из мессенджера (внесено)

Мессенджер отправляет файлы через `Kov.Files.upload()` напрямую, мимо
плиток файлов, поэтому прежний `uploadsActive()` их не видел: при
восстановлении связи раздел мессенджера перерисовывался, и отправка
отменялась — одинаково на сайте и в APK (проверено тестом).

Теперь `files.js` считает все вызовы `upload()`:

```js
  let direct = 0;   // отправки мимо плиток файлов (мессенджер зовёт upload() сам)
  function uploadsActive() { return activeJobs.size > 0 || direct > 0; }
```

а сама отправка обёрнута счётчиком (прежняя функция `upload` стала
`uploadNow`). Отсюда же на отправки из мессенджера распространились
остальные правила `app.js` — «связь пропала — отправка продолжится» и отмена
после двух минут без сети, — а в приложении окно «Идёт отправка файла»
появляется и при отправке в чат.

Проверка (UI-тесты, блок `fixes`): отправка в чат при восстановлении связи
доходит — на сайте и в APK; до правки тот же тест показывал «отменена».
