Сюда положите два файла из Firebase:

  google_key        — ключ сервера (Firebase → Настройки проекта → Сервисные аккаунты →
                      «Создать новый закрытый ключ»). Его подхватит сервер в Docker.
  google-services   — файл приложения (Firebase → Настройки проекта → Общие → ваше
                      Android-приложение). Из него сборка сама возьмёт значения.

Расширение .json у файлов может быть или не быть. Проверить ключи: run.cmd keys-check

Без этих файлов всё работает, но уведомления проверяются только через собственный
канал приложения. Это секреты — не пересылайте их и не кладите в архивы.
